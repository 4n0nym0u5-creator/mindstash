# Mindstash

A beautiful microlearning app inspired by Deepstash — bite-sized ideas from books and thinkers, stashed into your personal knowledge library.

## What you can do

- **Onboard** by picking topics you care about
- **Swipe through** a personalized daily feed of idea cards
- **Stash** ideas you love and group them into collections
- **Explore** topics, search the library, and open related ideas
- **Build a streak** as you read a little each day

Everything is stored in your browser (localStorage). No account required.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:3847](http://127.0.0.1:3847).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Framer Motion for card transitions
