# Mindstash

A beautiful microlearning app inspired by Deepstash — bite-sized ideas from books and thinkers, with illustrated cards, listening, book scan, and streak freezes.

## What you can do

- **Onboard** through a short story (hero → books vs insights → topics)
- **Swipe** a personalized daily feed of illustrated idea cards & quotes
- **Listen** to any idea with one tap (browser speech)
- **Scan books** (demo) to pull matching ideas from a cover
- **Build streaks** with a calendar, milestones, and freezes
- **Stash** ideas into collections in your library

Everything is stored in your browser (localStorage). No account required.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:3847](http://127.0.0.1:3847).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Framer Motion for card & onboarding transitions
