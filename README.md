# Mindstash

A sophisticated microlearning app — bite-sized ideas from books, thinkers, and hard-won life patterns. Illustrated cards, listening, book scan, streaks, and a deep library on relationships and narcissistic dynamics.

## What you can do

- **Onboard** with a guided quiz (topics, reasons, energy, learning style)
- **Read** a personalized daily feed of illustrated idea cards & quotes
- **Explore** topics including Narcissism, Relationships, and Boundaries
- **Listen** to any idea with one tap (browser speech)
- **Scan books** (demo) to pull matching ideas from a cover
- **Build streaks** with a calendar, milestones, and freezes
- **Stash** ideas into collections in your library

Everything is stored in your browser (`localStorage`). No account required.

## Hot topic: Narcissism & life partners

A dedicated topic with dozens of original insights on love-bombing, gaslighting, FOG, gray rock, trauma bonding, financial control, parallel parenting, recovery, and more — written for people navigating (or leaving) a narcissistic partner.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:3847](http://127.0.0.1:3847).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Framer Motion for card & onboarding transitions
